# 📊 E-Commerce Sales Dashboard (Microsoft Excel)

## Project Overview

This project is an interactive E-Commerce Sales Dashboard built using Microsoft Excel. It transforms raw sales data into meaningful business insights through data cleaning, analysis, KPIs, pivot tables, and interactive visualizations.

## Objective

The objective of this project is to analyze sales performance, customer behaviour, product performance, and profitability to support data-driven business decisions.

## Dataset

* Source: E-Commerce Sales Dataset
* File Type: CSV
* Data Cleaning & Transformation: Microsoft Excel Power Query

## Data Cleaning Process

* Removed duplicate records
* Handled missing values
* Standardized date formats
* Cleaned currency and numeric values
* Corrected inconsistent text entries
* Created calculated columns where required

## Excel Features Used

* Power Query
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* XLOOKUP
* INDEX-MATCH
* Dynamic Dashboard
* KPI Cards

## Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Profit Margin
* Top Selling Category
* Best Performing Region
